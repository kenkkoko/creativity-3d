# 01 需求釐清（階段 1）

## 需求
- **使用者**：想了解自己發想風格的學生、設計師、創意工作者，以及看作品集的面試官。
- **問題**：創造力看不見，也無法和別人比較。
- **輸入**：一個刺激詞，以及限時內寫下的聯想詞（每則可附一句「我怎麼想到的」）。
- **輸出**：3D 語義星圖（自己的聯想、所有使用者的分布）＋創造力指紋＋文字解讀。

## 新增需求：亂答防護（合理性門檻）
問題：亂打或完全無關的字，語義距離會很遠，會被誤判成很有創意。
原則：**遠而合理才算分**，有效距離 = 語義距離 × 合理性。

三層檢查：
1. **規則層（不呼叫模型）**：亂碼、鍵盤連打、非英文單字、重複、與刺激詞相同
2. **向量層**：距離超出全體分布的極端值 → 標記「待確認」
3. **LLM 層（Structured Output）**：請模型在 3 步以內找出「聯想橋」（apple → gravity → Newton）；找不到就判定不合理。使用者若有附註說明，就一併納入判斷。

## 風險
| 類型 | 對策 |
|---|---|
| 幻覺 | 分數全部由程式計算；LLM 只能引用算好的數字，輸出再比對一次 |
| 格式錯誤 | Structured Output + Pydantic 驗證，最多重試 3 次，再失敗就退回只有數字的版本 |
| 機密資料 | 送模型前先遮蔽個資；金鑰與設定放 `.env`；資料匿名儲存 |
| 離題使用 | 字數與則數上限、prompt injection 偵測、不雅字詞過濾 |
| 亂答灌分 | 上述三層合理性門檻 |
| 誤用分數 | 標示為「聯想風格指標」，用多維指紋呈現，不給單一總分 |
| 資料寫入 | 存入公共分布前，需經使用者同意（Guardrail：寫入前人工確認） |
